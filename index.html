About the software

About: SUBSTRATE PRO is a browser-based architectural drafting and BIM authoring workspace. It combines traditional drawing controls with model-linked data, coordinated plan/elevation/3D review, sheet composition, schedules, and publish-ready presentation output. This hosted edition is designed to stay compact and dependable while presenting a professional software identity.

What the software does

SUBSTRATE PRO is designed as a compact browser-hosted BIM drafting environment that lets a designer draw, edit, review, and publish coordinated model information from a single interface.

Drawing + modelingWalls, slabs, columns, beams, doors, windows, dimensions, linework, grids, and levels.
Model coordinationShared properties, linked object data, level assignment, and view-dependent review output.
DocumentationQuantities, schedules, orthographic review sheets, plot composition, symbols, and hatch graphics.
PublishingSVG export, PNG export, plots, guided presentations, and startup splash selection.

Recommended workflow

  • Start a new or sample project from the launcher dashboard.
  • Draft architectural geometry using the left-side discipline tools.
  • Review and edit BIM properties, levels, and hosted elements.
  • Generate schedules, sheets, and review plots from the same model.
  • Publish drawings and presentation outputs from the main toolbar.

Included feature families

  • Polyline wall drafting and 90-degree wall workflows
  • Snaps, grid control, level control, and model review views
  • Door and window symbols, material hatches, and assembly graphics
  • Plotting system with paper-space layout and title block workflow
  • Associative authoring, schedules, quantities, and export tools
